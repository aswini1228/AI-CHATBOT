# AI-CHATBOT

An AI-powered chatbot web application that allows users to interact with an Artificial Intelligence model through a simple and interactive chat interface.
The application is developed using Python, Streamlit, Hugging Face Transformers, and Hugging Face Hub.

**Live Application**

Try the AI Chatbot:
"Open AI Chatbot" (https://ai-chatbot-en9q5xd4z2my-ai-chatbothukai-chatboteu4ewljeh.streamlit.app/)

**Project Overview**

The AI Chatbot provides an interactive platform where users can enter questions or messages and receive AI-generated responses.

The application uses a pre-trained AI language model through Hugging Face and provides a user-friendly interface using Streamlit.

This project demonstrates the practical implementation of Artificial Intelligence, Natural Language Processing, and Generative AI in a web-based application.

**Key Features**

- Interactive chatbot interface
- AI-generated responses
- Simple and user-friendly interface
- Built using Streamlit
- Hugging Face AI model integration
- Real-time interaction
- Web-based deployment

**How It Works**

User
  ↓
Chatbot Interface
  ↓

  ↓

  ↓
Natural Language Processing
  ↓
AI Generated Response
  ↓
Chatbot Interface

Working Process

1. The user opens the AI Chatbot application.
2. The user enters a message in the chat interface.
3. The application receives the user's input.
4. The input is passed to the Hugging Face AI model.
5. The model processes the input using Natural Language Processing.
6. The AI generates a response.
7. The generated response is displayed in the chatbot interface.

Installation

Clone the Repository

git clone <your-github-repository-link>

Navigate to the Project Directory

cd AI-Chatbot

Install Dependencies

pip install -r requirements.txt

Run the Application

streamlit run app.py

The application will open in the browser.

Hugging Face Configuration

The chatbot uses Hugging Face to access the AI model.

For deployment, the Hugging Face access token should be stored securely using Streamlit Secrets or environment variables.

Sensitive tokens should not be directly added to the source code.

Deployment
